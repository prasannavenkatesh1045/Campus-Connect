# Campus Connect – Supporting Files

This package contains the Campus Connect MySQL database script and the supplied project image assets.

## Contents
- `database/campus_connect.sql` – creates the `campus_connect` database and its STUDENT, ADMIN, EVENT, and REGISTRATION tables, with sample records.
- `assets/` – supplied screenshots and the KPRIET emblem.

## Important
This is **not the complete PHP application source code**. The uploaded `Campus-Connect.zip` file was a web-page response titled “Cookie check”, not a valid ZIP archive, so it could not be extracted. PHP application files such as `index.php`, login pages, admin/student pages, and database connection code were not present in the uploaded files.

Do not describe this package as the complete working application. Add the actual PHP source files when they are available.
